# minus-lernspiel
Minus ZR 100 mit Levels

Eigenständige Version des Minus-Lernspiels von DENKAVO. Die Dateien `index.html`, `script.js` und
`style.css` sind identisch mit `public/minus/` der Lernplattform. Eingebettet in DENKAVO meldet das
Spiel Lernereignisse an die Plattform und zeigt den Haus-Knopf; eigenständig entfällt beides.

Stand: entspricht DENKAVO v0.6.1 (Vollbild-Knopf, Hoch-/Querformat-Anordnung, Eingabesperre,
Ergebnisfeld bei der Rechnung, Direkt-Knopf ohne Rechenschritte, Animationsknopf mit Bildsymbol).
